# Dream 100 of IMO/FMO/BGA/GA Principals — POPULATED Outreach List (Research-Driven)

## Purpose
This is the master outreach list for the IMO sales motion. 100 named IMO/FMO/BGA/GA principals, organized by segment, with the personalized outreach angle for each. The foundation of the public launch (months 7-9) and the IMO pipeline.

**Last updated:** June 30, 2026

**Important:** This is a research-driven first pass. The list focuses on the actual IMO/FMO/BGA/GA organizations that are the buyers (not upstream carriers like Prudential or Lincoln Financial, which are upstream suppliers). The LinkedIn search queries will help you find the actual principal at each organization. The personalized angles are tied to the segment. The scores are conservative.

**How to use this list:** Filter by priority tier (Hot first), then by relationship (start with your existing relationships, then go cold), then by segment. Use the LinkedIn search query to find the actual principal. Use the personalized angle as the conversation starter.

**How to update this list:** Every week, update the status column. Move prospects through the pipeline (not contacted → connection sent → connected → message sent → call scheduled → pilot → customer → lost). The list is a living document, not a one-time artifact.
